# Automobile Insurance Dashboard – Power BI Project

## 📌 Project Overview
This Power BI dashboard analyzes automobile insurance complaints, premium trends, and company performance over multiple years. The dashboard provides insights into complaint distribution, premium analysis, and insurance company rankings.

## 🛠 Tools Used
- Power BI
- Excel / CSV Dataset
- Data Visualization
- DAX Measures

## 📊 Dashboard Features
- Total Complaints Analysis
- Premium Trend Analysis
- Complaint Ratio Tracking
- Company Performance Summary
- Complaint Type Distribution
- Year-wise Trend Analysis
- Interactive Filters and Slicers

## 📈 Key Insights
- Comparison of complaint trends across companies
- Premium growth analysis over years
- Identification of top complaint-generating companies
- Company ranking based on performance metrics


## 🚀 How to Use
1. Download the `.pbix` file
2. Open it using Power BI Desktop
3. Refresh dataset if required
4. Explore interactive dashboard visuals
